1. Connect Telegram

You need your own API ID and API hash from my.telegram.org. Enter them here — they stay in this browser and are used only to talk to Telegram.

Where do I get the API ID and hash?
  1. Open my.telegram.org and sign in.
  2. Open API development tools.
  3. Create an application and copy the API ID and API hash here.

Telegram treats the API hash as a secret. Do not post it publicly.

    Privacy & security

    • Static site only — no application backend, database, proxy, or serverless API.
    • Your browser connects directly to Telegram over MTProto/WebSocket.
    • We never receive your API hash, phone number, login code, 2FA password, session, contacts, or chat contents.
    • Optional local storage: API credentials and/or session string may be saved in this browser if you opt in. Anyone with access to this device/browser profile could use them.
    • By default the session stays in sessionStorage (cleared when the tab closes) unless you choose “Keep me signed in”.
    • Use Log out / forget everything to erase local credentials and session data from this browser.

    No tool can honestly claim to be “100% secure.” Treat API hashes and sessions like passwords.
