Telegram Joined Cleaner

Remove “X joined Telegram” service chats safely.

Runs entirely in your browser. Your Telegram API credentials, login session, messages, and account data are never sent to this website.

1. Connect Telegram

You need your own api_id and api_hash from Telegram. They are entered directly into this browser session.

Where do I get the API ID and hash?
  1. Open my.telegram.org and sign in.
  2. Open API development tools.
  3. Create an application and copy the API ID and API hash here.

Telegram treats the API hash as a secret. Do not post it publicly or put it in the repository.
