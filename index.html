Telegram Joined Cleaner

This repository root is not the production site. GitHub Pages deploys the webpack build from web/dist via .github/workflows/pages.yml.

Production URL: https://pritkc.github.io/Telegram-mass-account-delete/

Local preview: cd web && npm ci && npm run build && npx serve dist

Do not open web/index.html directly — it expects the compiled app.js next to it, which only exists after npm run build inside web/dist/.
