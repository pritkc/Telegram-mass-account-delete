Telegram Joined Cleaner

Remove “X joined Telegram” service chats safely.

This page runs client-side. Telegram credentials, the login session, and account data stay in your browser and go directly to Telegram.

1. Connect Telegram

Use your own Telegram API ID and API hash from my.telegram.org.

Where do I get the API ID and hash?
  1. Open my.telegram.org and sign in.
  2. Open API development tools.
  3. Create an application and copy the API ID and API hash here.

Telegram treats the API hash as a secret. Never put it in this repository or send it to an intermediary server.
